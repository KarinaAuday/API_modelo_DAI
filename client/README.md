# Cliente React - API Modelo DAI

Este es el cliente React para la API Node.js.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

El cliente estará disponible en `http://localhost:5173`

## Características

- ✅ Listar, crear y eliminar provincias
- ✅ Listar y crear cursos
- ✅ Listar y crear alumnos
- ✅ Proxy automático de API requests a `http://localhost:3000`

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
